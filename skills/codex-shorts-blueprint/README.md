# codex-shorts-blueprint v2.0.0

Open SKILL.md for the active production workflow. Read references/research.pdf
for the compact research report or references/research.md for every timed
observation. The reference ledger contains nine verified million-view Shorts,
72 browser-rendered still samples and English automatic-caption metadata.

The skill adds visual proof, coherent scenes, 2.5D camera/occlusion workflows,
ten motion recipes, clearer typography/material rules and stronger QA while
retaining the user's original hook, safe-zone, pacing, 12fps paper-craft,
loop and three-stem constraints.

To reuse in another workspace, extract the codex-shorts-blueprint folder and
make its SKILL.md and bundled relative files available to Codex. The .skill
and .zip downloads contain the same portable folder; choose the format your
client accepts. This does not claim registration in a global cloud skill list.

Validate the included authoring example with Python 3:

    python scripts/validate_plan.py examples/rage-bait-premium-plan.json

The validator has no external Python dependencies. It checks plan structure
and the supplied constraints. Actual rendered frames, normal-speed movement,
source audio listening, final mix and the loop still require production review.
The example plan is not a newly rendered version of the rage-bait MP4.

No source video or audio downloads and no full third-party transcripts are
included. Contact sheets are visual research references. View counts are dated
public totals, not private retention, engaged-view, swipe or revenue metrics.
After Effects recipes are implementation guidance; no native AE project or
executed AE render is claimed.
