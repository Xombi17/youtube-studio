# Content Ideas Queue

Track every content idea from capture to publish. Update status as the idea moves through the production pipeline.

---

## Status Key

| Status | Description |
|---|---|
| `idea` | Raw idea captured, not yet researched |
| `research` | Fact-checking and research in progress |
| `scripted` | Script complete, awaiting storyboard/production |
| `produced` | Video rendered and edited, awaiting QA review |
| `approved` | Human-approved, ready to upload |
| `published` | Live on YouTube |
| `blocked` | Stuck — missing asset, rights issue, or needs info |
| `dropped` | Decided not to produce |

## Priority Key

| Priority | Criteria |
|---|---|
| `HIGH` | Time-sensitive (pre-launch or launch-window), high search demand |
| `MEDIUM` | Evergreen or moderate demand, flexible timing |
| `LOW` | Nice-to-have, low urgency |
