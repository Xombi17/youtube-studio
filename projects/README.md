# Projects Directory

This directory holds local video production projects generated by CreatorRadar production workflows (e.g. `vox-explainer`, `production-pipeline`, etc.).

## Git Policy
- **All subdirectories inside `projects/` are ignored by git.**
- Projects remain local to your workstation to keep the engine repository lightweight and clean.
- Never commit individual video production project files, frame sequences, audio stems, or intermediate video clips.
